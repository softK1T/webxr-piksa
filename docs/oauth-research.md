# Исследование: вход через внешнюю учётную запись

## Текущее решение
Логин и пароль, хеш `scrypt` (соль 16 байт), сессия в httpOnly cookie с HMAC-SHA256 подписью и сроком 7 дней.

## Варианты внешнего входа
| Провайдер | Протокол | Плюсы | Минусы |
|---|---|---|---|
| Google | OpenID Connect | Популярен, стабильный | Нужен проект в Google Cloud, HTTPS redirect URI |
| GitHub | OAuth 2.0 | Прост для разработчиков | Нет OIDC id_token, нужен запрос `/user` |
| HTC VIVE / VIVEPORT | Проприетарный SDK | Привязка к устройству | Нет открытого веб-OAuth для WebXR |

## Особенности VR
На HTC VIVE Focus 3 ввод текста виртуальной клавиатурой неудобен. Удобнее Device Authorization Grant (RFC 8628): шлем показывает короткий код, пользователь подтверждает вход на телефоне.

## Схема интеграции
1. Authorization Code + PKCE на backend (FastAPI, библиотека Authlib).
2. Таблица `oauth_accounts (user_id, provider, subject)`.
3. После callback выдаётся та же cookie `piksa_session`.

## Вывод
Для базового задания достаточно логина и пароля. OAuth не реализуется, схема выше позволяет добавить его без изменения существующей модели сессии.
